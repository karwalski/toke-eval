# Benchmark solutions — v0.4 (133.4 Part B)

The 1000 reference solutions in `benchmark/solutions/task-a-NNNN.toke`, brought to
toke v0.4. Part A (ids 0001–0060) is `docs/gate1-60-v04.md`; this note covers the
whole set as it stands after Part B.

**What the gates are.** `tkc --check` clean, and the existing harness
(`benchmark/run_benchmark.py --language toke`: build with `tkc`, run
`bin <json-input>`, compare stdout as JSON) passing every test case of the id.
`scripts/solutions_v04.py` runs both and reads back only the harness's JSON
report (pass/total per id); it never opens a test file and discards the
harness's stdout/stderr.

**Reproduce** (tests for 0501–1000 are in `benchmark/hidden_tests/`; 0001–0500
are in the archived toke-benchmark copy — pass that directory as a second
`--tasks-dir`):

```
TKC=~/tk/toke/tkc python3 scripts/solutions_v04.py \
    --tasks-dir benchmark/hidden_tests --tasks-dir <dir with task-a-0001..0500> \
    --json /tmp/solutions-v04.json --md docs/solutions-v04.md   # regenerates the block below
```

## Residue and what blocks it

- **127.214** (a local or parameter named like an import alias, `s`, makes
  `s.slice(…)` resolve to `std.str.slice`: false E4026) — the 23 E4026 ids
  0074 0076 0082 0085 0086 0116 0152 0161 0162 0166 0182 0183 0184 0185 0186 0187
  0196 0236 0240 0276 0278 0281 0309. Not worked around in the solutions.
- **E4031, program error plus 127.214** — 0233 (indexes a `str` with `.get`;
  local `s`), 0235 (passes an `@i64` element as `str`; parameter `s`).
- **127.215** (`j.print` of a str from a user function or str method prints
  the pointer) — sized with a probe that only annotates `:str` on such bindings
  (scratch, not committed): of the 130 check-clean ids that fail the harness, 12
  had a matching binding. 5 pass in full with the annotation (0073 0231 0232
  0239 0293) and 6 gain cases but still fail (0077 0150 0159 0181 0197 0237);
  0308 is unchanged. This is a lower bound: the probe does not reach str
  values printed through other routes. 0077 also compares a sliced `str` with
  an int and passes `--check` (noted in 127.215).
- **127.213** — no id still blocked (0153 and 0259 were the only originals
  using `^`; both hand-fixed).
- The other check-clean harness failures are not classified yet (wrong
  program or an unfiled defect); they are listed in the generated block.
